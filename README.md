# RAG-чатбот по документам

Учебный проект по дисциплине «ООП. Современные паттерны» (Москва, 2026). Планируется настольное приложение для работы с PDF, DOCX и TXT: ответы на вопросы с указанием источника. Одна кодовая база должна поддерживать внешнюю модель с ключом пользователя и локальную модель для документов, которые нельзя передавать третьим лицам. Повторный вопрос при неизменном индексе должен обслуживаться из кэша.

[Предыдущий прототип](https://github.com/Tkhn-one/Rag-chatbot_docs) используется как источник идей; история этого проекта ведётся отдельно.

**Состояние проекта:** этап 0 — подготовка заявки. Сейчас в репозитории только документы. Исходников, CMake и тестов нет; сборка и запуск пока недоступны. Предлагаемые технологии и состав MVP требуют проверки на следующих этапах.
