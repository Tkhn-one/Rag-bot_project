# RAG-чатбот по документам (рабочее название)

Учебный проект по дисциплине «ООП. Современные паттерны» (проектная траектория).
Прежний прототип: https://github.com/Tkhn-one/Rag-chatbot_docs — используется как источник идей; история ведётся с первого коммита этого репозитория.

## Что это

Десктопное приложение для обычного пользователя: добавляете свои PDF/DOCX/TXT и задаёте вопросы — получаете ответы со ссылками на файл и страницу.

- **Конфиденциальное издание (локальная модель):** документы не покидают компьютер, интернет не нужен.
- **Издание с внешним API:** работает с ключом пользователя (OpenAI-совместимые сервисы: GPT, DeepSeek, Grok, OpenRouter).
- **Экономия:** повторные вопросы отвечают из кэша и не расходуют API.

Подробнее: `docs/PROJECT_BRIEF.md`, `docs/PRODUCT.md`.

## Требования

- CMake 3.20+ и компилятор с поддержкой C++20 <!-- или: Python 3.12+ -->
- Git

## Сборка

```bash
cmake -S . -B build
cmake --build build
```

## Запуск

```bash
./build/app          # Windows: build\Debug\app.exe
```

## Тесты

```bash
ctest --test-dir build --output-on-failure
```

## Структура

```
src/domain          — сущности и правила предметной области
src/application     — сценарии
src/infrastructure  — файлы, сеть, БД, логирование
src/presentation    — CLI (GUI — как расширение)
tests/              — тесты
docs/               — PRODUCT.md, ARCHITECTURE.md, DECISIONS.md, AI_LOG.md, METODICHKA.md
```

## Документация

- `docs/PRODUCT.md` — пользователь, проблема, границы MVP
- `docs/ARCHITECTURE.md` — слои, классы, зависимости
- `docs/DECISIONS.md` — реестр архитектурных решений
- `docs/AI_LOG.md` — журнал существенных эпизодов работы с ИИ
- `CHANGELOG.md` — изменения каждой версии (v0.1 … v1.0)
