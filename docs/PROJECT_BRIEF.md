## Тема

**RAG-чатбот по документам как десктопное приложение для обычного пользователя** (не для разработчика): пользователь добавляет свои PDF/DOCX/TXT и получает ответы по ним со ссылками на источник и страницу.
**Одна кодовая база — два варианта поставки:** тонкий клиент с внешним API (ключ пользователя) и локальное издание со встроенной llama, работающее полностью офлайн. Повторные вопросы не расходуют API — ответы кэшируются.

## Требования преподавателя

| № | Требование | Реализация |
|---|---|---|
| 1 | Платформа для обычного пользователя, не «питон-бэкендер» | Настольный GUI (слой Presentation) поверх Domain/Application; GUI — расширение, а не замена архитектуры (п. 5 методички) |
| 2 | Повторный вопрос не должен делать новый запрос к API (себестоимость при монетизации) | Кэш ответов: ключ = нормализованный вопрос + версия индекса + id модели; инвалидация при изменении документов; счётчик сэкономленных запросов |
| 3 | Два варианта приложения | Одна кодовая база, две сборки: THIN (внешний API) и FAT (встроенная llama) |
| 4 | Выбор нейросети | Провайдер как заменяемая деталь: интерфейс `ILlmProvider`, реализации `RemoteApiProvider` и `LocalLlamaProvider`, `MockProvider` для тестов |
| 5 | Монетизация | Разовая покупка + ключ пользователя (вариант A). Подписка с вендорским API вне рамок текущей версии: требует сервера-прокси для защиты ключей (ADR-007) |
| 6 | Документы, которые нельзя передавать третьим лицам | Режим «Только локально» на уровне библиотеки: внешние провайдеры заблокированы, проверяется тестом «ноль сетевых вызовов» (ADR-008) |

## Открытые вопросы

1. **Платформа GUI:** Qt 6 + CMake (рекомендация — нативно для C++, один бинарник, кроссплатформенно) / Tauri + C++ ядро / PySide6 (требует согласования языка). → ADR-003
2. **Способ хранения индекса** (чанки + эмбеддинги локально, без серверной БД). → ADR-006
3. **Модель и лицензия** для локальной сборки (вес GGUF, требования к RAM/VRAM, условия распространения весов).
4. **Хранение ключа API** пользователя: системное хранилище (Windows Credential Manager / macOS Keychain) или файл конфигурации. → ADR-009
5. **Язык проекта:** C++20 (по умолчанию) или Python (требует согласования с преподавателем). → ADR-001

## Определение готовности MVP

Пользователь ставит приложение, добавляет папку с документами, задаёт 5 вопросов, получает ответы с цитатами (файл + страница), закрывает и открывает приложение — история и индекс сохранены; повторный вопрос отвечает мгновенно из кэша без обращения к API, и приложение показывает, что запрос не был потрачен.
Документ, помеченный «только локально», обрабатывается без единого сетевого запроса — проверяется тестом и демонстрируется на защите.
